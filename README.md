# 💼 Portfolio Webpage

A personal portfolio website created as a minor project during the **Avaintern Full Stack Internship**.

The website presents professional and academic information through a responsive, visually focused single-page experience.

## ✨ Sections & Content

The portfolio includes information about:

- Work experience
- Education
- Contact details
- Interests
- Certifications
- Personal/professional profile

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap

## 🎨 Design

The website uses a **wine-colour themed visual design** with Bootstrap components and a small amount of JavaScript for smooth webpage scrolling. Bootstrap makes navigating the website easier on mobile phones.

## 📁 Project Structure

```text
Portfolio-Webpage/
├── CSS Bootstrap/
├── Images/img/
├── Javascript_Scroller/
├── Aastik Gupta Portfolio- Code.html

```

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/3112aastikg/Portfolio-Webpage.git
cd Portfolio-Webpage
```

Open `index.html` in your browser.
